A real connection requires a provider such as Plaid, developer credentials, a secure backend, and a privacy/security review. Never enter bank passwords into this prototype.

To enable bank linking, a developer must configure a provider account, create a server endpoint to generate short-lived link tokens, exchange public tokens securely, and implement transaction sync and consent handling. The provider secret must never be placed in this HTML file.
